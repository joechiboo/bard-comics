# Prompt 校稿筆記

校稿迭代中發現的 prompt 修正經驗，持續累積。改 prompt 前先翻這份，別重踩同一個坑。

寫法約定：通用原則放上面（跨場適用），逐場案例放下面（帶頁/格編號，方便回查）。
確定的寫結論；還沒驗證的標「⏳ 待驗證」。

## 通用原則

### Prompt 撰寫

- **顏色詞在黑白畫風下不可靠**：style_suffix 是黑白墨線風，生圖模型常直接忽略顏色描述（見 1-1 案例：grey cat 生成全黑貓）。若顏色是劇情辨識重點，改用**明暗與材質**描述（如 `light-furred` / `pale`），或乾脆放棄顏色改用形狀特徵。
- **角色 token 要靠近主詞**：token（獨眼、白瞳、裂嘴笑）放在該角色描述的緊鄰位置，不要堆在句尾，多人同格時才不會張冠李戴。⏳ 待驗證（1-1 多為單人特寫，1-3 女巫同框再確認）
- **一格一個視覺焦點**：prompt 塞太多主體時，模型會自己挑一個畫，其他的變背景雜訊。想要的東西只有一件就只寫一件。⏳ 待驗證
- **否定句不可靠**：`he wears no crown, bare head` 照樣畫出戴冠（1-3 p8-1 二連敗實錘）。物件只要出現在角色附近的 prompt 裡，就會被裝到角色身上；不想要的東西**別提**，想要「在別處」的東西用獨立載體承接（如水窪倒影、背景剪影），別靠介係詞或否定詞。
- **臉部形容詞堆疊會翻掉畫風**：token 一次塞太多臉部描述（`in her late thirties, sharp angular facial features, a cold piercing gaze` 三連發）會把格推成**寫實肖像照風**，蓋掉 style_suffix 的墨線漫畫，連帶構圖（讀信、燭光）與特許色（深紅袍變黑）全丟——1-5~7 夫人臉第一輪補強實錘。補強要精簡：一次加**一個**關鍵詞（如 `a stern angular face`），不夠再疊，每輪目檢。
- **同話同主體多格必須顯式換鏡位**：seed 固定 42 之下，「同角色＋相近描述」的格會長出近乎相同的構圖（5-1 夫人持燭三格實錘、1-3 p8 兩格側臉實錘，感知雜湊掃描確認）。每格 prompt 開頭就寫死鏡位——`view from behind`／`side profile extreme close-up`／`very wide shot`／`high angle looking down`／`over-the-shoulder`——讓相鄰格的取景詞彙互斥，別都用泛泛的 close-up/medium shot。

### 快取與重生

- 快取鍵 = provider + 尺寸/比例 + prompt 全文的雜湊：**prompt 改一個字就整格重生**，校稿時確定要改再改。
- 只改 `dialogue`/`quote` 不動 `prompt` → 零生圖成本，排版問題盡量往對白/排版端解。
- pollinations 的 seed 固定 42：同 prompt 必得同圖。想要「同 prompt 換一張」，得改 prompt（加無害的措辭變化）。

### 供應商特性（pollinations / flux）

- 黑白墨線 style_suffix 吃得很穩，五頁下來調性一致，氣氛掌握（荒原、閃電、剪影）是強項。
- 弱項在**角色跨格一致性**與**多人互動構圖**：1-1 p2-1 三女巫同框已確認「個別特徵全滅」；馬克白左頰疤的跨格穩定度 ⏳ 待 1-2/1-3 出圖驗證（主角級指標）。
- 免費服務尖峰時慢，429/5xx 靠腳本內建退避重試，掛掉重跑即可（有快取不浪費）。
- 速度實測（2026-07-30 離峰）：約 45s/格、很穩（39–64s，連跑 39 格零重試）。估工時用 45s×格數，尖峰另計。

## 排版端待改（不是 prompt 的鍋，別浪費重生額度）

- 音效目前和對白共用白底圓角框，「音效感」偏弱 → 之後改成畫在圖上的描邊大字（pipeline backlog，同 README 氣泡尾巴一項）。

### 1-5~7 夫人臉補強（2026-07-31，token 場內補強）

- 現象：p1-2 等格夫人臉偏娃娃臉、圓潤（對照基準：3-4 p4-1 的冷冽銳利）。
- 處置：**場內** `characters` 欄 token 補強（canon 原文不動，先驗證再談推廣）。
- 第一輪（三連發臉部形容詞）：❌ 臉成熟了但**畫風翻成寫實肖像照**、紅袍變黑、讀信構圖丟失
  ——教訓入通用原則「臉部形容詞堆疊會翻掉畫風」。
- 第二輪（只加 `a stern angular face` 一詞）：❌ 仍翻成寫實肖像風、讀信構圖仍丟
  ——證明**不是形容詞數量問題**：這幾格的 prompt 結構（token 開頭＋簡短場景）本來就在
  肖像照邊緣，原版能落在墨線風可能是運氣。單靠 token 補強救不了臉，已**還原 canon 原文**（停損）。
- 後續方向（擇日再戰）：改「格 prompt 端」而非 token 端——把鏡位寫遠（seated at a desk,
  medium shot from across the table）、把 letter/candle 寫成畫面主角，或 style_suffix 前置。
  夫人臉問題降級為「已知可接受」，deployed 首輪草稿維持現狀。
- 附註：本容器 cache 不進版控＝跨 session 快取歸零；seed 固定 42 同 prompt 必得同圖，
  重跑只花時間不會飄，未改 prompt 的格重生後與已上站圖一致。
