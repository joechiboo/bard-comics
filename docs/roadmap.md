## 建議動線

1. **跑 1-1＋1-2 首輪生圖**（共 29 格；⚠️ 2026-07 實測 gemini 免費層生圖額度已為 0，首輪改走 pollinations 零 key 備案，見 README 供應商表）
   驗證三件事：畫風是否穩定、角色 token 跨格一致性（尤其馬克白左頰疤）、對白框與置右題字壓在真實畫面上的效果。
2. **校稿迭代**：改 prompt 只重生改過的格（快取按 prompt 雜湊）。改前先翻、改完記錄 → docs/prompt-notes.md。
3. **定成品存放與閱讀頁**：
   - 定稿 PNG 搬進版控（建議 `shakespeare/macbeth/1-1/p01.png ...`，`pages/` 仍為工作區不進版控）
   - 做一個場次閱讀頁模板（卡片點入 → 直向滾動看整話）
4. **開後續分鏡**（每場先定案新角色 token，再寫 JSON）：
   - 弒君之夜：涵蓋原著 2-1（刀的幻象）＋ 2-2（行刺後），**需先定案馬克白夫人 token**
   - 夫人夢遊：原著 5-1
   - 最終決戰：併場原著 5-3 ~ 5-9（挑「明天、明天、明天」「勃南森林」「非婦人所生」三個錨點）
5. **回頭補場**（MVP 驗證後視情況）：1-5/1-7 夫人慫恿、3-4 宴會鬼魂、4-1 大釜咒。

## 量級備忘

- 一格 = 一張生圖。MVP 五場約 70–110 張；全劇 28 場約 400–600 張（120–200 頁）。
- pollinations 免費（校稿迭代用）；gemini 需開帳單約 $0.039/張（MVP 約 $5 內）；OpenAI medium 約 $0.04–0.06/張。
- gemini 免費層生圖額度 2026-07 已實測為 0（`limit: 0`），別再指望免費額度。

## 工序 SOP（每一場）

```text
朱譯原文（docs/text-sources.md 的來源）
  → 挑段改寫台詞（text=白話改寫、en=莎翁公版原文，逐句都要帶）
  → 新角色 token 進 docs/characters.md 定案
  → 切頁切格寫 prompt（經典名句加 quote 欄位＝置右題字）
  → python tools/generate_comic.py storyboards/<scene>.json
  → 校稿（改 JSON 重跑，只重生改過的格；心得記進 docs/prompt-notes.md）
  → 定稿 PNG 進版控、更新場次卡片與閱讀頁
```
