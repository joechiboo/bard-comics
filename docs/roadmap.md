## 量級備忘

- **生圖速度（2026-07-30 實測，pollinations 離峰）**：約 45 秒/格（39–64s，39 樣本）。
  一集短的（14 格）≈ 10 分鐘；長的（26 格）≈ 20 分鐘；第一幕 86 格 ≈ 65 分鐘；全劇 400–600 格 ≈ 5–7.5 小時純機器時間，掛背景跑即可。
  校稿迭代只重生改過的格：改 3 格 ≈ 2 分多鐘。尖峰時段可能明顯變慢；gemini 出定稿時通常數秒到十幾秒/張，瓶頸轉為人工校稿。

- 一格 = 一張生圖。MVP 九話約 155–175 張（已寫 95＋未寫估 60–80）；全劇 13 話約 220–280 張（90–110 頁）。
- pollinations 免費（校稿迭代用）；gemini 需開帳單約 $0.039/張（MVP 約 $5 內）；OpenAI medium 約 $0.04–0.06/張。
- gemini 免費層生圖額度 2026-07 已實測為 0（`limit: 0`），別再指望免費額度。

## 工序 SOP（每一場）

```text
朱譯原文（docs/text-sources.md 的來源）
  → 挑段改寫台詞（text=白話改寫、en=莎翁公版原文，逐句都要帶）
  → 新角色 token 進 docs/characters.md 定案
  → 切頁切格寫 prompt（經典名句加 quote 欄位＝置右題字）
  → python tools/generate_comic.py storyboards/<scene>.json
  → 校稿（改 JSON 重跑，只重生改過的格；心得記進 docs/prompt-notes.md）
  → 定稿 PNG 進版控、更新場次卡片與閱讀頁
```
