# 莎劇文本來源與版權整理

台詞底本的取得管道與版權原則。新增劇目時先查這份文件。

## 版權原則

| 譯者/版本 | 狀態 | 說明 |
| --- | --- | --- |
| 朱生豪 中譯 | ✅ 公版 | 1944 年過世，著作權已消滅，可自由引用與改寫 |
| 梁實秋 中譯 | ❌ 版權期內 | 1987 年過世，台灣著作權（死後 50 年）至 2037 年底，**不可直接使用** |
| 莎士比亞 英文原文 | ✅ 公版 | 1616 年過世，原文完全公版 |
| 現代學術版英文（Arden、Oxford 等） | ⚠️ 註解有版權 | 劇本正文公版，但編者註解、導讀不可抄 |
| Folger Shakespeare 電子文本 | ⚠️ CC BY-NC | 非商業使用可，需標示來源；若網站有營利打算避開 |

## 注意事項

- 朱生豪生前譯了 31 部半，部分歷史劇（亨利五世、亨利六世中下篇、理查三世等由方平等人補譯）**補譯部分不是公版**，做到這些劇目時需另查
- 網站台詞是以朱譯為底的現代口語改寫，不逐字照搬；經典名句可附英文原文（公版）對照
- 分鏡 JSON 的每句 dialogue 都要帶 `en` 欄位：有原文的台詞放莎翁公版原文（寫分鏡時順手對照存入，事後補要逐句回查）；音效、自創旁白放英譯。目前生圖排版只用 `text`，`en` 是為未來英文版／雙語對照預留的資料
